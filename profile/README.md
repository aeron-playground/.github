## How we work

- **In the open.** Issues, plans, reviews and the roadmap are public. Security reports are the only exception.
- **Every change is a pull request.** Nobody pushes to `main`, maintainers included. Machines check
  formatting, types, tests and security. People review the ideas.
- **A history you can read.** Commit messages follow [Conventional Commits](https://www.conventionalcommits.org).
  We squash-merge pull requests and build changelogs and releases from that history.
- **Clear rights.** Every commit is signed off under the [Developer Certificate of Origin](https://developercertificate.org).
- **Secure by default.** We turn on secret scanning and push protection, check every new dependency for
  known vulnerabilities, scan code with CodeQL and pin every GitHub Action to a full commit hash.
