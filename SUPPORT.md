# Support

How to get help with aeron playground projects.

| You want to | Go here |
| :--- | :--- |
| Ask how to use or build a project | The project's Discussions, under Q&A. For example, [Opentrail Q&A](https://github.com/aeron-playground/Opentrail/discussions/categories/q-a) |
| Share an early idea | The project's Discussions, under Ideas |
| Report a bug | The project's issues. Search first, then use the bug report form |
| Ask for a feature | The project's issues, once the idea is concrete |
| Report a security problem | Privately, as the [security policy](https://github.com/aeron-playground/.github/blob/main/SECURITY.md) explains. Never in public |
| Report a Code of Conduct problem | Email [agab0323@gmail.com](mailto:agab0323@gmail.com) |

## What to expect

- We read everything and usually reply within a few days.
- There is no paid support.

## Ask a good question

- Say what you tried, what you expected and what happened instead.
- Add the version or commit, your operating system and the commands you ran.
- Paste logs as text, not screenshots. Remove tokens, keys and personal data first.
